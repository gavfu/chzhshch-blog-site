# Noto Sans SC (subset)

These `.woff2` files are subsets of **Noto Sans SC** (weights 400/500/700),
licensed under the SIL Open Font License 1.1 (see `OFL.txt`). They cover the
full site corpus plus GB2312, so the site self-hosts its fonts instead of
loading them from Google's font CDN (blocked in mainland China).

Generated by `tools/fonts/make_subsets.py` in the **chanxilu** repo. When the
corpus changes, regenerate the subsets there and copy the output back here.
